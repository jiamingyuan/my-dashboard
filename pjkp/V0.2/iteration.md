## 决定与实现结果

| 决定 | 来源、状态与依据 |
| --- | --- |
| 运行时 JSON 注册 | 为不同项目独立构建和部署提供宿主能力；已实现 public/modules.json，默认 version=1、modules=[]。其 version 是清单格式版本，与产品 V0.2 / npm 0.2.0 无关 |
| 使用已验证的 Vite 插件与运行时 | @module-federation/vite 1.23.5、@module-federation/runtime 2.9.2；React / React DOM 19.3.1、React Router 8.5.0 延续当前基线，通过 shared singleton 协作 |
| 动态菜单和子路由 | 注册的启用工具自动进入 sidebar，路径为 /tools/:moduleId/*；未知或停用模块显示 404，不伪造业务页面 |
| React 组件契约 | 远程默认导出组件；宿主传 theme、basePath、path、search、navigate。对其他框架暂未实现直接适配；详细类型与接入方式引用正式文档 |

# my-dashboard 项目简介

> 状态：V0.1 前端基础框架已按现有 Figma 双主题实现并通过本版验证，待用户验收；未加入业务模块。来源：2026-10-21 当前对话与实际代码、测试结果。

## 项目介绍

### 项目定位

`my-dashboard` 是一个包含前端与后端的个人工具网站，用模块化的方式接入用户自己做的工具，并通过侧边栏（sidebar）提供各工具的访问入口。

### 项目概要

用户从网站 sidebar 选择工具模块并进入对应功能。用户给出的模块示例包括 AI 日报、背单词、media-keeper，后续还希望能够接入其他自制工具。

当前已有项目文档、可本地运行的前端外壳及 Figma 界面草稿（[晨间模式](https://www.figma.com/design/P2EfZNJYj2PsdZLmaMzHMN?node-id=14-266) / [夜间模式](https://www.figma.com/design/P2EfZNJYj2PsdZLmaMzHMN?node-id=4-86)）。Figma 草稿中的业务模块、内容和数值为布局示例，V0.1 不实现这些业务能力；各工具未来如何与网站协作仍待后续需求。

用户已确认前端采用 React + TypeScript + Vite，V0.1 已实现前端基础工程。后端是否需要独立建设及其具体方案仍待结合模块需求确定，当前没有后端。

用户选择 V0.1，要求先基于现有 UI 搭建前端框架、不加任何模块；完成 pjkp plan 后，于 2026-10-21 明确授权执行。当前交付包括可运行工程、侧栏、顶栏、晨间 / 夜间主题、搜索空白占位、无工具空状态、通用 404 和小屏导航。类型检查、lint、构建与 11 项 Chromium 回归通过，详见测试结果；尚待用户验收。AI 日报、背单词、media-keeper 的入口、业务卡片及示例内容均未迁入框架。

2026-10-21 用户追加要求使用已有 debian:trixie，创建名为 my-dashboard 的容器并放入项目运行。首次通过 Nginx 完成静态运行；随后用户要求直接在容器里开发并删除宿主副本，项目现以 `my-dashboard-project` 持久化卷保存在容器 `/app/my-dashboard`。容器包含 Node、Git、Python 和 Chromium 测试工具，Vite 提供热更新，访问 http://localhost:8080。该操作没有加入业务模块、后端或公网托管，也不代表 V0.1 已验收。

2026-10-21 用户指定上传到 [GitHub 仓库](https://github.com/jiamingyuan/my-dashboard)。项目已在容器内初始化 Git 并上传 main，首次项目内容提交为 a099f26ff560fd6b7023d20c0a7516b6d7867a9b；远端 290 个文件已与本地 Git 清单核对一致。源码、配置与 pjkp 已归档，依赖和本机运行产物留在项目卷中。后续仍在容器内开发；上传不代表网站托管或 V0.1 验收。

### 项目价值

- 将自己做的多个工具集中到同一个网站入口。
- 通过模块化接入，为继续加入工具保留空间。

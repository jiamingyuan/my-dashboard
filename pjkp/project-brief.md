# my-dashboard 项目简介

更新：2026-10-23。当前版本为 V0.2；核对了本版源码、配置和现有运行容器。

## 项目定位与长期方向

将用户自己开发的工具集中到一个网站，通过 sidebar 选择和使用各模块。用户最初设想包含前端和后端，示例工具为 AI 日报、背单词、media-keeper；这些名称不等于已交付功能或已确定的下一版清单。

来源：2026-10-20 用户要求“这个项目是一个包含前后端的网站，能够将我做的一些工具通过模块化的方式接进来”。前端随后由用户从 Vue 3 改为 React，沿用 TypeScript 与 Vite。

## 当前能力

| 能力 | 现状 |
| --- | --- |
| 前端外壳 | V0.1 已实现侧栏、顶栏、总览、通用 404、小屏导航与无工具空状态 |
| 晨间 / 夜间 | 同一套组件切换语义色，手动选择本地保存，存储异常仍可切换 |
| 搜索位置 | 保留桌面透明留白，没有搜索输入、快捷键或搜索能力 |
| 模块化接入 | V0.2 已实现 Module Federation；读取运行时 JSON 清单，生成菜单和模块路由，按需加载远程 React 组件 |
| 模块协作 | 宿主传递主题、模块根路径、子路径、查询串与导航函数；远程加载或渲染失败时提供提示和重试 |
| 业务工具 | 正式清单为空；AI 日报、背单词、media-keeper 均未接入，测试 fixture 不计为业务模块 |
| 后端与账户 | 宿主尚无后端、数据库接口、登录或权限功能；本机 MySQL 服务的存在不代表项目已使用数据库 |
| 运行 | 本机 Node.js 开发，构建后由独立 Nginx 容器在 http://localhost:8080 提供静态页面，无 Volume |

V0.1 与 V0.2 的实际结果、用户来源和验证限制分别见 [V0.1 迭代记录](V0.1/iteration.md)、[V0.2 迭代记录](V0.2/iteration.md)。测试通过和继续迭代均不补写为用户验收。

## 已确认的方向与尚未确定的范围

- 用户希望不同项目定义的 UI 能接入宿主页；当前支持独立构建、独立部署的远程 React 组件。宿主不需要包含各工具源码；接入方法见 [模块说明](../docs/modules.md)。
- Figma 晨间 / 夜间参考保留在 [设计文件](https://www.figma.com/design/P2EfZNJYj2PsdZLmaMzHMN)。稿内业务内容与数字仅为设计示例。
- 后端是否独立建设、各模块 API 与数据存储、登录权限、公网部署、域名及 HTTPS 尚未确定；没有自行排入后续版本。
- 当前未指定要接入的真实子模块项目或远程地址，也没有未来版本号和交付日期。
